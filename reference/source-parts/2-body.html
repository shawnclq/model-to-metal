From the model to the metal.

Learn the GenAI stack layer by layer, with a simulator that runs in your browser, from how a model is built down to a multi-node GPU cluster. Load real open models onto H100s and Blackwells, split them across GPUs and servers, start a Ray cluster, and fix what breaks: models that won't fit, slow tokens, idle GPUs, crashing prompts, mismatched drivers, slow networks.

Each level sets up one problem. Change the hardware, precision or software with the buttons or the terminal, hit the objectives, then read how it connects to the rest of the stack. Fewer hints means more stars. Turn on Show the math any time for the formulas.
